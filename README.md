# DevOps Git Task 3

This repository demonstrates Git workflow best practices.

## Objectives
- Create branches (`main`, `dev`, `feature`)
- Make commits and pull requests
- Resolve conflicts
- Use `.gitignore`, `README.md`, and `TASKS.md`
- Create a tagged release (v1.0.0)

## Branches
- **main** → Stable branch
- **dev** → Development branch
- **feature/*** → Feature development branches
